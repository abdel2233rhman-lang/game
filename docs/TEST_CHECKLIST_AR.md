# قائمة الاختبارات بعد النشر (Supabase الحقيقي + جهازان مختلفان)

**الأجهزة:** جهاز A (مضيف، مثلًا موبايل) وجهاز B (لاعب، مثلًا كمبيوتر على شبكة أخرى إن أمكن). يفضّل جهاز C (لاعب ثالث) في الاختبارات 4-6.
سجّل لكل بند: ✅ نجح / ❌ فشل + ملاحظة/لقطة شاشة.

## أ) قبل اللعب: قاعدة البيانات (قراءة فقط)
- [ ] استعلامات التحقق في دليل النشر (الخطوة 4) كلها بالنتائج المتوقعة (45 شخصية، 21 دالة، القيد، الحاوية، Realtime).
- [ ] أعداد الصفوف القديمة (rooms/players/games/...) = "اللقطة قبل".

## ب) لوحة الأدمن
- [ ] `/?admin=characters` تعرض شاشة دخول.
- [ ] بيانات خاطئة → رسالة خطأ، ولا دخول.
- [ ] حساب سليم **غير** مضاف لـ `bus_admins` → "ليس ضمن قائمة المسؤولين".
- [ ] حساب الأدمن يرى 45 شخصية، والبحث والتصفية بالتصنيف يعملان.
- [ ] إضافة شخصية اختبارية بتلميحين فقط وهي مفعّلة → رفض (يلزم 3).
- [ ] إضافة شخصية اختبارية صحيحة (3 تلميحات + بديل واحد) → تظهر في القائمة.
- [ ] رفع صورة JPG ثم PNG ثم WEBP → تظهر مصغّرة. رفع ملف PDF أو صورة >2MB → رسالة رفض.
- [ ] تعطيل ثم تفعيل شخصية يعمل. حذف الشخصية الاختبارية بعد تأكيد.
- [ ] تسجيل الخروج يعيد لشاشة الدخول.

## ج) إنشاء الغرفة والانضمام (A + B)
- [ ] A: إنشاء غرفة → اختيار "خمن الشخصية" → تظهر شاشة اللعبة بكود من 6 خانات.
- [ ] نسخ الكود والرابط يعملان.
- [ ] B: الدخول بالكود، ثم تجربة الدخول **برابط الدعوة** (`?room=`) → يظهر B عند A لحظيًا بدون Refresh.
- [ ] اسم مكرر في نفس الغرفة → رفض. غرفة ممتلئة → رفض.
- [ ] تغيير الإعدادات من A (الوضع، الجولات، الثواني، الأسئلة، التصنيفات) يظهر عند B لحظيًا، وأزرار B معطلة.
- [ ] تقليل التصنيفات حتى يصبح عدد الشخصيات أقل من الجولات → يظهر تنبيه ويتعطل زر البدء.
- [ ] B لا يستطيع بدء اللعبة. A بلاعب واحد فقط لا يستطيع البدء.

## د) جولة كاملة (Classic، 3 جولات، 45 ثانية)
- [ ] ضغط "ابدأ": يظهر العد التنازلي 3-2-1-GO عند الجهازين معًا (فرق أقل من ثانية).
- [ ] المؤقت متطابق تقريبًا في الجهازين طوال الجولة.
- [ ] ظهور التلميح 1 فقط في البداية، ثم تلميحات تتكشف تدريجيًا **في نفس اللحظة** عند الجهازين، مع صوت خفيف.
- [ ] B: إجابة خاطئة → رسالة وصوت، وتنقص المحاولات (3 ثم 2 ثم 1 ثم 0). المحاولة الرابعة مرفوضة.
- [ ] B: نفس الإجابة الخاطئة مرتين → "أرسلت هذه الإجابة من قبل".
- [ ] A: إجابة صحيحة مبكرة → +100 (+20 للأسرع) في الشاشة والترتيب، وتظهر علامة "خمّن الشخصية" عند B **دون** كشف الاسم.
- [ ] A لا يستطيع إرسال إجابة صحيحة ثانية في نفس الجولة (لا نقاط مكررة).
- [ ] B: إجابة صحيحة بعد ظهور 3 تلميحات → 60 نقطة بلا بونص.
- [ ] الأسئلة: ضغط سؤال → الإجابة تظهر للجميع في "النشاط"؛ نفس السؤال لا يُسأل مرتين؛ استنفاد الحد → تعطّل الأزرار.
- [ ] عند انتهاء المؤقت أو إجابة الجميع → شاشة الكشف: الاسم + كل التلميحات + نقاط كل لاعب.
- [ ] A (المضيف) يضغط "ابدأ الجولة التالية" يتخطى الانتظار. B لا يملك الزر. وإن لم يضغط أحد تبدأ الجولة وحدها بعد 10 ثوانٍ.
- [ ] الجولة الأخيرة → شاشة النتيجة النهائية بالمنصة والترتيب الصحيح.
- [ ] "العب مرة أخرى" عند المضيف فقط → نفس الغرفة والكود، النقاط صفر، وتعود إعدادات اللوبي.

## هـ) الأوضاع الأربعة
- [ ] **Mystery:** لا صورة أبدًا (حتى لو رُفعت صورة)، ويظهر مربع "؟".
- [ ] **Progressive:** الصورة (بعد رفع صورة لشخصية) ضبابية جدًا وتتضح مع كل تلميح.
- [ ] **Fast:** بونص +50 للأول، وتنتهي الجولة بعد ~5 ثوانٍ من أول إجابة صحيحة.
- [ ] **Classic بلا صورة مرفوعة:** يظهر شكل رمادي محايد وليس صورة مكسورة.
- [ ] افتح أدوات المطوّر → Network → استجابة `char_get_state` أثناء الجولة: **لا يظهر اسم الشخصية** ولا التلميحات المغلقة.

## و) الانقطاع وإعادة الاتصال
- [ ] B يغلق التبويب في منتصف جولة ثم يفتح الموقع من جديد → يعود لنفس الغرفة بنفس النقاط وبنفس مرحلة اللعب.
- [ ] B يفصل الإنترنت 10 ثوانٍ ثم يعيده → تعود المزامنة تلقائيًا ويظهر شارة الاتصال.
- [ ] تبديل التبويب (خلفية) ثم الرجوع → تحديث فوري للحالة.
- [ ] تحديث الصفحة (Refresh) عند المضيف أثناء الجولة لا يوقف اللعبة.

## ز) المضيف واللاعبون المغادرون
- [ ] A (المضيف) يضغط "غادر الغرفة" أثناء اللعب → يصبح B المضيف وتظهر له أزرار التحكم.
- [ ] A يغلق المتصفح فجأة (دون مغادرة) ويبقى صامتًا أكثر من **45 ثانية** → ينتقل دور المضيف تلقائيًا للاعب نشط (مؤشر الاتصال عند A يصبح رماديًا قبلها).
- [ ] مع 3 لاعبين: خروج لاعب لا يوقف اللعبة. بقاء لاعب واحد فقط → تنتهي المباراة بالنتيجة.
- [ ] الانضمام لغرفة بدأت فعلًا → "بدأت المباراة بالفعل".

## ح) واجهة وصوت وأجهزة
- [ ] الموبايل (عمودي) والكمبيوتر: لا عناصر مقطوعة، النص العربي RTL سليم.
- [ ] زر كتم الصوت يعمل ويحفظ اختيارك بعد Refresh.
- [ ] أصوات صحيح/خطأ/تنبيه/عدّ تنازلي تعمل بعد أول نقرة (قيد المتصفحات على الصوت التلقائي).

## ط) التأكد أن الموجود لم يتأثر
- [ ] RISK IT: إنشاء غرفة عادية (اللعبة الأولى) بلاعبين ولعب جولة كاملة (رهان، سؤال، كشف) دون أي تغيير.
- [ ] غرفة RISK IT وغرفة خمن الشخصية **في نفس الوقت** من أجهزة مختلفة لا تتداخلان.
- [ ] الانضمام بكود غرفة RISK IT يفتح RISK IT، وبكود خمن الشخصية يفتح خمن الشخصية.
- [ ] استعلامات "أعداد الصفوف" بعد الاختبار: الأعداد القديمة لم تنقص (ستزيد بغرفك التجريبية فقط).
- [ ] (إن كان لديك Bus Complete في بيئتك) غرفه ومسؤولوه كما هم.

## ي) أمان سريع (يدوي)
- [ ] قراءة الشخصيات بمفتاح anon العام يجب ألا تُرجع بيانات (من أي طرفية؛ بدّل القيم بقيمك):
  ```bash
  curl "https://xxxx.supabase.co/rest/v1/characters?select=*" -H "apikey: مفتاح_anon" -H "Authorization: Bearer مفتاح_anon"
  curl "https://xxxx.supabase.co/rest/v1/character_rounds?select=*" -H "apikey: مفتاح_anon" -H "Authorization: Bearer مفتاح_anon"
  ```
  المتوقع: `[]` أو خطأ صلاحيات (`permission denied`)، **وليس** قائمة شخصيات أو أسماء.
- [ ] مفتاح `service_role` غير موجود في متغيرات Vercel ولا في الكود.
- [ ] ملف `.env` غير موجود في مستودع GitHub.

## نتيجة الاعتماد
لا تدعُ الأصدقاء قبل نجاح **كل** بنود (ج) و(د) و(و) و(ز) و(ط). فشل أي بند: وثّق الخطوات + لقطة الشاشة + رسالة الخطأ وأرسلها لي.
